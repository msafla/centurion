# Maquettes CENTURION

Maquettes de référence pour la Synthèse et les Référentiels, alignées sur
`DESIGN.md` (Poppins, violet `#451DC7`, accent vert, surfaces plates, rayons 8 px,
actions en pilule). Les captures réelles de l'application exécutée sont dans
`docs/screenshots/`.

## Synthèse (`summary.md`)

- Bandeau de synthèse violet compact en tête, chiffres réels.
- Quatre cartes : total, à renseigner, réalisés, non réalisés.
- Trois taux avec numérateur/dénominateur visibles.
- Tableau « prochaines occurrences » (cinq premières `open` à venir).

## Référentiels (`references.md`)

- Trois catégories distinctes (ISO 27001, ISAE 3402 Type 2, ISO 27001 + ISAE 3402
  Type 2).
- Agrégation de contrôles et de résultats, mention « suivi, pas couverture
  certifiée ».
- Aucun calcul de couverture de clauses.

Ces maquettes ont été rédigées après l'implémentation de T7 afin de refléter la
mise en page réellement livrée ; elles documentent la cible visuelle et ne
remplacent pas les captures d'exécution.
